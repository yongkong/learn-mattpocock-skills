# AGENTS.md

Guidance for coding agents working in this repo.

## Agent skills

### Issue tracker

Issues are tracked on GitHub at `yongkong/learn-mattpocock-skills` (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Default triage labels are used: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
