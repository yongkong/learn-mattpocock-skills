# 语域标准(Register)

公开站「Agent Skills 中文课」全部内容的写作标准,由 wayfinder 决策票 [#11](https://github.com/yongkong/learn-mattpocock-skills/issues/11) 定案(2026-09-18)。约束对象:公开化改造施工,以及未来的每一份新课件。

## 总纲

> **写给只读网页的零背景读者:课件自成一体,不依赖会话、不依赖时点、不指涉作者沙盒。写完默读一遍,像教材,不像聊天记录。**

- 读者画像:对 agent skills 体系零背景的中文开发者,第一次打开站点,无人指导。
- 作者角色:教材的写作者,不是对话中的私教;课程与读者之间不存在「当前会话」。
- 本总纲是「课件必须自成一体」内部纪律的公开版升级,后续细则皆为它的推论。

## 人称与语气

- 第二人称一律用「你」,全站不混用「您」。
- 语气标尺:可朗读的教学书面语——默读像教材,不像聊天记录。
- 高频替换示例(给方向,不穷举,按标尺灵活判):

| 口语 | 书面 |
|------|------|
| 彩蛋级连接 | 关联机制 / 延伸连接 |
| 白做 | 前功尽弃 / 徒劳 |
| 甩一排 #42 | 列出一排编号 |
| 挑毛病 | 审查 |
| 发车 | 发布 / 上线 |

## 禁语清单(三类)与替换策略

1. **作者私指**:不出现「使命」类指涉作者个人文件的概念(如「本课与使命的关系」)。
   → 改写为「本课目标:学完你能做什么」。
2. **会话耦合**:不假设读者正与作者或任何 agent 同处对话。禁「问你的老师(就是我)」「直接在对话里问」「困惑正是下一节课最好的素材」。
   → 改为指向词典 / 速查 / 出处链接,或「到仓库 issue 区提问」。
3. **时点与沙盒绑定**:禁「今日」「本仓库」「.scratch/」等只对作者成立的指涉。
   → 通用化(「你配置的 issue tracker」「你自己的仓库」)。间隔复习用相对说法(「第 1、3、7 天」)是正例。
   - **案例研究例外**:允许保留具体工程细节,但必须明标「案例:本站诞生记」,且措辞按「你自己的仓库」通用化。

## 引用规范(依据决策票 #8 的引用边界结论)

- 每个论断:链接 + 出处,不裸奔。
- 英文短引:句级以内,标注出处;成段转载不可。
- 中文转译:加「(中译)」标注;整篇翻译不可。
- SKILL.md 体系与术语的结构性教学复用:依据上游 mattpocock/skills 的 MIT 授权;由关于/致谢页承担非官方声明与致谢义务。
- 词典:中文释义为原创转述(站点 CC BY-SA 4.0 覆盖);术语与英文原文版权归原作者,上游仓库未附开源许可;保留「原文 ↗」链接。
- **口径一致性**:同一概念跨文档表述冲突时,以上游 SKILL.md 原文为准,两处应互链。
